### 🚀 In Development: [SRTEV](https://github.com/SRTEV)
**Electric vehicle rental and tracking system.**  
A platform for renting electric scooters, reporting malfunctions, and monitoring fleet technical condition.

*   **[ScooterAPI](https://github.com/SRTEV/ScooterAPI):** API for electric scooter simulation (`Flutter`).
*   **[Main Application](https://github.com/SRTEV/MainAPP):** Mobile app for customers and repair technicians (`Flutter`).
*   **Admin Panel:** Comprehensive dashboard for fleet management:
    *   **[Frontend](https://github.com/SRTEV/WebFrontend):** `React`
    *   **[Backend](https://github.com/SRTEV/WebBackend):**  (An API for secure data exchange between an application, a admin panel, and a database)`.Net` .
